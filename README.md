 # TripSplit

A smart trip expense manager to track shared expenses, split bills among selected members, and see who owes whom, all in one place.

**Live Demo:** https://shahil-prajapati.github.io/TripSplit/

## Features
- Create trips and add members
- Track expenses with custom categories
- Split an expense among selected members
- Automatic balance calculation
- Settlement tracking
- Modern glassmorphism UI with dark mode

## Tech Stack
- HTML, CSS, JavaScript (vanilla)
- Data stored in the browser using localStorage
- Structured so Firebase can be added later for cloud sync

## How to Run
1. Download or clone this repository
2. Open `index.html` in any browser

## Note
Data is stored only in your browser (localStorage), so it stays on your device.
